# Лабораторна робота: Robot Repair

Проєкт створено в рамках лабораторної роботи з Unity.

## Виконано:
* Налаштовано 2D URP проєкт у Unity (версія 6.3)
* Імпортовано та налаштовано ассет **Adventure Game: Robot Repair**
* Продемонстровано запуск гри та перемикання артів (стилів)
* Налаштовано `.gitignore` для Unity

## Щоденник розробника

### Юніт 1: Персонаж і рух
У цьому юніті я створила основну сцену MainScene та налаштувала підлогу з тайлів за допомогою Tilemap. Для плиток було виставлено PPU = 64 та Order in Layer = -10, щоб підлога відображалася коректно і не перекривала персонажа. Також я створила та підключила скрипт PlayerController з використанням Input System. Персонаж плавно рухається у чотирьох напрямках за допомогою стрілочок та клавіш WASD. Для незалежності швидкості від кадрової частоти (FPS) було використано Time.deltaTime.

###Юніт 2: оточення і фізика
**Що зроблено:** 
Створено та налаштовано ігровий рівень за допомогою Tilemap. Налаштовано фізику руху персонажа (PlayerCharacter) через Rigidbody2D та Input System, застосовано фізичний матеріал NoFriction (Friction = 0) для усунення тертя. Виправлено взаємодію з колайдерами води та усунуто тремтіння персонажа біля стін.

**Що не вийшло або забрало найбільше часу:** 
Найбільше часу пішло на вирішення проблеми із застряганням і липненням персонажа до межі водойми під час руху під кутом. Збереження змін у префабі PlayerCharacter та налаштування Composite Collider 2D вимагали декількох спроб перевірки.

**Що зрозумів про FixedUpdate і колайдери:** 
Зрозумів, що фізичне переміщення об'єктів за допомогою Rigidbody2D.MovePosition потрібно виконувати строго у FixedUpdate з використанням Time.deltaTime для стабільності. Також зрозумів, що прямокутні кути Box Collider 2D можуть зачіплятися за стики тайлів, тому використання Capsule Collider 2D (або заокруглення кутів) та відсутність тертя є критичними для плавного ковзання.

**Що в рівні вийшло не так, як у фізичному паспорті, і чому:** 
Загальне розміщення елементів відповідає плану, проте розміри колайдера персонажа та налаштування Composite Collider 2D для Tilemap довелося коригувати «на ходу», щоб уникнути мікро-застрягань на стиках сітки.

**Що робитиму далі:** 
Реалізацію механіки шкоди та лікування робота, створення лічильника здоров'я
